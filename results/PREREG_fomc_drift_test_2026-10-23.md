# PRE-REGISTRATION 2026-10-23 (committed BEFORE the first real run): is the market's return unusually high in the two days up to a scheduled FOMC announcement (the 'pre-FOMC drift')?
SCRIPT: scripts/card/fomc_drift_test.py (read-only). DATA: SPY adjusted closes from market_prices (1994-01-03 to 2026-10-13, 8,250 days, complete), fomc_meetings (all scheduled meetings; the decision day = the meeting's last day; from 2000 every scheduled meeting has a statement, before 2000 only changes did, so before 2000 the meeting day is used regardless).
STATISTIC. log return r(t) = ln(SPY(t) / SPY(t-1)); two-day window R2(i) = r(i-1) + r(i) for the decision day i; EXCESS(i) = R2(i) minus the mean of R2 over baseline days 21-63 trading days away, excluding EVERY meeting day (scheduled and unscheduled) and the day after (fed_change_day_test.ld, the same machinery as the size tests). Reported in percent; t = mean / (sd / sqrt(meetings)).
POPULATION: scheduled meetings only (unscheduled actions are excluded from the test and from the baseline). Windows: REPLICATION 1994-2011 (the published sample of Lucca and Moench, who measured 2:00 pm to 2:00 pm returns on the S&P 500); PERSISTENCE 2012-2026; descriptive project eras 2004-2014 and 2015-2026.
RULE. REPLICATES: mean excess > 0 with t >= 2.5 in 1994-2011 and the +21 / -21 shifted placebo clean (|t| < 2.5). PERSISTS: mean excess > 0 with t >= 2.0 in 2012-2026. VERDICT: 'REPLICATES AND PERSISTS' if both; 'REPLICATES, FADED' if only the first; 'NOT REPLICATED' otherwise (including a void placebo, reported as VOID). The REPLICATION line is also the instrument check: if a published effect of about 0.5% a day is invisible at this resolution, later nulls from this test mean little.
DESCRIPTIVE ONLY (exploratory): day -1, day 0 and day +1 returns separately (excess over the same baseline) per window and per project era.
PREDICTIONS (point and range): 1994-2011 two-day excess +0.30% (+0.05 to +0.55), P(t >= 2.5) 40%; 2012-2026 +0.08% (-0.20 to +0.35), P(t >= 2.0) 12%; P(REPLICATES AND PERSISTS) 8%, P(REPLICATES, FADED) 32%, P(NOT REPLICATED or VOID) 60%; scheduled meetings about 260 (250-270) over 1994-2026.
LIMITS: close-to-close two-day returns dilute a 24-hour window (day 0 also contains the announcement reaction, whose mean is about zero but whose noise is large); the per-meeting sd of a two-day SPY return is about 1.6%, so the standard error is about 0.13% with 144 meetings (a 0.33% effect is needed for t 2.5); SPY adjusted closes include dividends (a small positive bias on ex-dividend days, equal in baseline and event days); direction only, the size result is separate.
