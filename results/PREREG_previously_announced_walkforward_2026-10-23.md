# PRE-REGISTRATION 2026-10-23 (committed BEFORE the first coverage computation for this group): does a multiplier fitted on the earliest era fix the coverage of non-acquisition 'previously_announced' event-days in later eras?
ORIGIN (stated honestly): post hoc. The pooled class table of event_band_class_coverage.py (commit 18f5c1d) showed 'previously_announced' coverage outside acquisitions of about 87%; that pooled figure includes every era, so this is NOT a clean held-out test of the hint. It tests whether an adjustment FITTED on 2005-2012 alone transfers to 2013-2019 and 2020-2026.
POPULATION (counts read first by event_band_pa_population.py, which prints no coverage): single-event stock-days (the audit's population: 2005+, exactly one labeled event, no earnings window, finite band unit) with timing = previously_announced and event type other than acquisition: 1,575 / 1,434 / 1,321 per era (2005-2012 / 2013-2019 / 2020-2026), minimum 1,321 against the audit's per-era minimum of 300. Subgroup capital_raise (360 / 405 / 403; the only single type above 300 in every era) is DESCRIPTIVE only; regulatory and the other types dip below 300 in at least one era and are not tested alone.
PROCEDURE. unit = band unit / m (the card's own multiplier; m = 1.0 if none); covered = unit <= edge (1.337). FIT on 2005-2012 only: k = (90th percentile of unit) / edge. Held-out eras: unadjusted coverage c0 = P(unit <= edge); adjusted coverage c1 = P(unit <= edge * k), the same k, no refit.
RULE (gate band 88-92%, as the audit's gate). 1. If unadjusted coverage in the FIT era is inside 88-92%: NO SHORTFALL IN THE FIT ERA (nothing to fit). 2. Else if unadjusted coverage is inside 88-92% in BOTH held-out eras: NOT REPLICATED (the shortfall is specific to the fit era). 3. Else if adjusted coverage is inside 88-92% in BOTH held-out eras and in each of them |c1 - 90| <= |c0 - 90| + 1 point: PASS (the multiplier transfers). 4. Else: FAIL.
PREDICTIONS (point and range): fit-era unadjusted coverage 88.0% (85-91); k 1.05 (1.00-1.12); P(NO SHORTFALL IN THE FIT ERA) 35%, P(NOT REPLICATED) 15%, P(PASS) 30%, P(FAIL) 20%.
STAKES. The group is 4,330 of 31,579 single-event stock-days from 2005 (13.7%); a perfect fix of a 3-point shortfall moves pooled event-day coverage by about 0.4 points. LIMITS: post hoc origin; k is a single scalar (no type or size structure); nothing on the card changes from this (day_card.py is frozen until the role-band verdict); if PASS, a card note or an interaction term is registered separately.
